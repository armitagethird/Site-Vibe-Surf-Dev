CASO · MOTEL PARAÍSO 2026

Motel Paraíso

Ecossistema de três frentes — cada peça atualiza independente, cada peça sobrevive se a outra cai.

  • Site público em Astro 5 + Tailwind v4 — Lighthouse 95+, zero runtime, indexável no Google.
  • Sistema local em Tauri + React — roda offline na recepção, integra com maquininha de cartão.
  • Dashboard remota em Next.js + IA — você vê ocupação, ticket médio, padrões de horário em tempo real.
  • IA processa os dados crus e devolve insights (não só gráfico): tendência da semana, melhor dia da semana, alerta de queda.
  • Cada frente tem independência: site cai? recepção continua. Internet caiu? sistema local opera offline.
  • Dado fica com você — sem aluguel mensal de servidor de outro.

Como funciona o ecossistema

Três frentes, uma operação inteira.

FRENTE 01 — SITE

Cliente reserva

Site público em Astro — carrega rápido, indexa no Google, mostra suítes, preços e disponibilidade. Cliente reserva sem ligar.

FRENTE 02 — RECEPÇÃO

Recepção opera

Sistema desktop em Tauri — check-in, check-out, controle de suítes, integração com maquininha. Roda offline; sincroniza quando a internet volta.

FRENTE 03 — DONO

Você observa

Dashboard web em Next.js — abre no celular, vê ocupação ao vivo, resumo do dia, da semana, do mês. IA marca o que sai do padrão.
